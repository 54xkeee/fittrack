# FitTrack 交互架构合同（Round 1）

**状态：** 实施目标。此合同先约束新的前端行为；既有页面在迁移前保持业务可用。

## 1. 渲染器与职责

- QML 是唯一正式训练渲染器。
- C++ Controller 与 `RestTimer` 是训练事实、事务、持久化和后台计时的唯一来源。
- React 训练页仅保留为视觉原型，不进入 Android 或桌面生产训练流。
- App Shell 负责一级导航、Back、安全区、Overlay 和全局反馈；页面不自行创建第二套导航壳。

## 2. 一级目的地

| 目的地 | 负责内容 | 不负责内容 |
|---|---|---|
| 首页 | 今日训练、近期进度、最近活动 | 训练编辑和历史详情。 |
| 计划 | 系统/个人计划、训练日入口 | 正式训练会话。 |
| 训练 | 活动训练、未完成训练恢复、自由训练入口 | 长期分析或管理。 |
| 动作 | 动作库、收藏、自定义动作、详情 | 训练流程导航。 |
| 分析 | 趋势、历史、有氧及数据相关入口 | 完成训练后的临时总结宿主。 |

底部导航只切换上述稳定目的地。训练准备、训练中、完成总结、详情和编辑属于流程或 Overlay，不是新的底部 Tab。

## 3. 训练工作流

```text
首页 / 计划 / 自由训练
        ↓
训练准备
        ↓ 开始
活动训练
        ↓ 完成本组
休息运行 / 暂停 / 跳过
        ↓ 所有动作完成后请求结束
完成确认
        ↓
训练总结
        ├─ 返回来源
        └─ 附加有氧 → 有氧完成后返回来源
```

- 开始训练时记录 `sourceDestination` 与必要来源上下文。
- 取消训练准备回到来源入口。
- 训练总结不通过“分析 > 历史”间接呈现。
- 恢复与放弃是活动训练的显式分支，不隐含在普通返回操作中。

## 4. Back 规则

Back 的处理顺序固定如下：

1. 关闭顶部 Overlay。
2. 关闭详情或编辑表面，回到其来源。
3. 退出训练准备，回到训练来源。
4. 活动训练中打开训练操作 Sheet，不直接销毁训练。
5. 从非首页一级目的地回首页。
6. 首页交给系统处理退出。

训练顶栏的 Back 只表达上述训练返回语义。训练命令放在 More/操作 Sheet，不复用 Back 图标。

## 5. 表面使用规则

| 行为 | 表面 | 关闭后行为 |
|---|---|---|
| 参数、替换动作、选择器械、排序、编辑已完成组 | Modal Bottom Sheet | 回原训练或准备上下文。 |
| 动作详情 | 全高 Sheet 或详情页面 | 回调用来源与滚动位置。 |
| 删除、放弃、提前结束、不可逆恢复 | Confirm Dialog | 默认焦点为取消。 |
| 动作级命令 | More Menu 或 Action Sheet | 不抢走页面焦点。 |
| 保存成功、删除可撤销、短状态 | Snackbar | 可选 Undo；不阻塞流程。 |
| 输入错误 | 字段下 Inline Error | 聚焦第一个错误字段。 |
| 页面加载、空、失败 | 页面级状态 | 提供明确下一操作。 |

中心 Dialog 不用于选择器、参数、详情、排序或常规编辑。

## 6. 训练中的持续状态

- 当前动作、当前组、训练进度始终在首要视觉层级。
- 休息计时使用固定 Bottom Action Bar；用户滚动时仍可查看、暂停和跳过。
- 完成本组后顺序为：提交中 → 成功确认 → 当前组完成 → 休息栏出现 → 下一任务可见。
- 已完成组可以编辑，但编辑入口不能与“完成当前组”竞争。

## 7. 反馈与无障碍合同

| 事件 | 可见反馈 | 触感 | TalkBack |
|---|---|---|---|
| 完成本组 | 组行完成态、休息栏 | 轻确认 | 只播报完成和休息开始。 |
| 训练完成 | 总结进入 | 明确确认 | 播报训练完成。 |
| 可撤销删除 | Snackbar + Undo | 无 | 播报删除和 Undo 可用。 |
| 输入失败 | Inline Error + 焦点 | 无 | 播报错误摘要。 |
| 每秒计时 | 数字刷新 | 无 | 不播报。 |

- 所有交互目标至少 48dp。
- 所有 Overlay 可通过 Back/Escape/可访问关闭控件退出。
- `reducedMotion` 启用时，非必要动效改为即时切换。

## 8. 最小动效合同

- 按下：100 至 120ms 状态层或缩放反馈。
- Bottom Sheet：从底部进入，可拖拽关闭；不超过 250ms。
- 完成本组：只动画状态变化、当前任务迁移和休息栏出现。
- Snackbar：底部进入、超时退出、Undo 保持可达。
- 不使用循环装饰动画、全屏庆祝动画或无语义位移动画。

## 9. Round 1 验证走查

以下路径在进入 Round 2 前必须完成低保真走查：

1. 首页开始训练 → 准备 → 取消 → 回首页。
2. 计划开始训练 → 准备 → 取消 → 回原计划日。
3. 活动训练 → 完成本组 → 休息 → 暂停/跳过 → 下一组。
4. 活动训练 → 请求结束 → 未完成组确认 → 总结 → 返回来源。
5. 动作详情、参数编辑、排序、删除分别使用正确表面并正确回焦点。
