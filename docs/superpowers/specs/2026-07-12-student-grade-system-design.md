# 学生成绩管理系统设计规格

## 1. 目标与范围

使用 Qt 6 Widgets、qmake 和 MinGW 实现一个 Windows 桌面端学生成绩管理系统。项目必须满足《Qt大作业教程_助教版(无代码).pdf》中的登录、管理员、学生查询、文件导入导出和 Windows 发布要求。

前端视觉稿由 Google Stitch 生成，实际产品使用 Qt Designer `.ui` 文件和 QSS 复刻，不嵌入 Web 页面。

不包含数据库、网络服务、多用户权限、在线同步、密码修改或记住密码。

## 3. 技术方案

- Qt 6 Widgets 原生桌面应用
- qmake 构建系统
- MinGW C++ 工具链
- Qt Designer 管理 `mainwindow.ui`、`adminwindow.ui` 和 `studentwindow.ui`
- QSS 负责 Stitch 校园蓝视觉复刻
- CSV/TXT 文件负责数据持久化
- Qt Test 负责非界面核心逻辑测试

## 4. 系统结构

### 4.1 MainWindow

登录窗口负责收集账号和密码，区分管理员登录与学生登录，并打开对应窗口。密码输入框使用 `Password` 显示模式。

管理员凭据固定为 `xmu123 / 123456`。学生账号为 `231202501` 至 `231202560`，密码为对应的 `password01` 至 `password60`。学生登录还必须能在已加载数据中找到该学号。

### 4.2 AdminWindow

管理员窗口展示所有学生成绩，提供导入、添加、删除、按总分排序、导出和返回登录页功能。表格整行选择、不可直接编辑，列顺序为学号、姓名、性别、英语、语文、数学、总分、平均分、排名。

添加学生时校验学号非空且唯一，性别只接受男或女，三科成绩范围为 0 至 100。删除操作必须先选中行并通过确认对话框。

### 4.3 StudentWindow

学生窗口接收当前学生数据，显示学号、姓名、性别、英语、语文、数学、总分、平均分和排名，并可返回登录页。

### 4.4 StudentData

`StudentData` 表示一条学生记录，保存学号、姓名、性别和三科成绩。总分与平均分由程序计算，不信任导入文件中的派生数值。

### 4.5 GradeRepository

`GradeRepository` 统一管理学生集合、文件读取、文件写入、学号查找、总分排序和排名更新。窗口不直接解析文件。

## 5. 数据流与规则

1. 程序启动时从可执行文件目录自动加载 `grade.csv`。
2. 初始 `grade.csv` 由用户提供的 60 人 CSV 复制而来，保留无表头 8 列格式。
3. 管理员导入 CSV 或 TXT 后，新数据整体替换当前内存数据。
4. 每次加载、添加或删除后，重新计算总分、平均分和排名。
5. 排名使用竞赛排名：同总分同名次，后续名次跳号，例如 `1、2、2、4`。
6. 平均分在界面中保留两位小数。导出文件保留与导入兼容的无表头 8 列格式，不单独写入平均分。
7. 管理员的添加和删除只修改内存数据。只有点击导出才写入用户选择的文件，不自动覆盖初始 `grade.csv`。

## 6. 视觉设计

采用已确认的 Stitch A 方案：现代校园教务系统风格，浅色背景，主色为 `#1890FF`，使用适度圆角、清晰层级和统一按钮样式。不使用复杂渐变、玻璃拟态、动画或 Qt Widgets 难以复刻的特效。

- 登录窗口：370 x 280，白色登录卡片，校园蓝标题，管理员和学生登录是主要操作，退出是次要操作。
- 管理员窗口：860 x 620，顶部标题和数据数量，中部九列表格使用交替行底色，下方是添加表单和底部功能按钮。
- 学生窗口：420 x 480，顶部显示基本信息，重点突出总分、平均分和排名，三科成绩分区显示。

## 7. 错误处理

以 `QMessageBox` 向用户报告可恢复问题，包括：

- 账号或密码错误
- 启动数据文件不存在或不可读
- 导入文件列数、字段类型或成绩范围不合法
- 学号重复或表单字段不合法
- 删除时未选中表格行
- 导出路径不可写

启动自动加载失败时，登录窗口仍可打开，管理员可登录后手动导入数据；学生登录会提示找不到成绩。

## 8. 测试与验收

### 8.1 自动测试

Qt Test 覆盖：

- 无表头 8 列 CSV/TXT 的正常解析
- 列数错误、非数字成绩、超范围成绩和重复学号的拒绝
- 总分、平均分和竞赛排名计算
- 按总分降序排序
- 管理员和学生凭据验证
- 导出后重新导入的数据一致性

### 8.2 手动验收

按照教程完成：

1. 管理员正确登录与错误密码提示。
2. 启动后自动显示 60 条数据。
3. 导入、添加、删除、排序和导出均可用。
4. `231202501 / password01` 以及 `231202560 / password60` 可查看对应成绩。
5. 三个窗口之间跳转正确，不会意外退出或重复创建可见窗口。
6. 密码显示为星号，表格整行选中且不可直接编辑。
7. Stitch 校园蓝风格在三个 Qt 窗口中保持一致，文字无裁切、控件无重叠。

## 9. 发布交付

1. 安装并配置 Qt 6 Widgets、MinGW 和 qmake 工具链。
2. 构建 Debug 和 Release 版本。
3. 使用 `windeployqt` 创建独立发布目录。
4. 发布目录包含可执行文件、Qt 运行库、平台插件和 `grade.csv`。
5. 交付完整源码、`.ui` 文件、QSS、测试、Stitch 项目链接、可运行发布目录和简明使用说明。
