# FitTrack 隐私与使用说明

生效日期：2026-07-13

适用版本：FitTrack 0.1.x

## 数据如何处理

FitTrack 是离线优先的个人训练记录工具，不提供账号、云同步、广告或行为分析。训练计划、动作收藏、训练重量与次数、训练备注、有氧记录、可选平均心率、健身房和器械信息都保存在用户设备上的本地 SQLite 数据库中。

当前 Android 应用不申请联网权限，也不会把上述数据发送给开发者或第三方服务器。动作资料只显示离线文字、本地图片和文本署名，不提供教学视频或媒体外链入口。

## Android 权限

应用使用通知和前台服务权限维持组间休息倒计时，并在计时自然结束时发出一次系统提示。应用不申请定位、相机、麦克风、通讯录、传感器或 Android 健康数据权限。拒绝通知权限不会阻止训练记录，但后台倒计时完成提醒可能不可用。

## 导出、恢复和删除

用户可以通过 Android 系统文档选择器主动导出 JSON 备份或 SQLite 快照，并从 JSON 恢复。导出的文件由用户选择位置和管理，不会上传到开发者服务器；这些文件可能包含完整训练记录，当前不进行额外加密，请勿发送给不可信对象。

应用已关闭 Android 自动备份。应用内删除功能会删除对应记录；卸载应用会删除应用沙盒中的本地数据库，但用户另行导出的备份文件不会被自动删除。

## 健身与医疗边界

FitTrack 只记录和可视化用户输入的数据。训练容量和估算 1RM 仅用于观察个人历史趋势，不构成医疗诊断、治疗建议或个性化训练处方。存在疼痛、疾病、运动风险或其他健康疑问时，应咨询医生或具备资质的专业人员。

## 变更与联系

如应用以后增加联网、账号、云同步、广告或分析功能，本说明必须在发布前更新，并在应用内明确提示。当前版本的问题与反馈请联系向你提供 APK 的发布者。
