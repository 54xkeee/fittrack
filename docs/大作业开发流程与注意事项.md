# Qt 大作业开发流程与注意事项

## 建议开发流程

1. **先跑通现有项目**
   - 直接运行 `dist\StudentGradeSystem\StudentGradeSystem.exe`。
   - 用管理员和学生账号分别走一遍主要功能。
   - 阅读 `README.md`，熟悉数据格式和构建命令。

2. **熟悉项目结构**
   - `app/*.ui`：三个 Qt Designer 界面。
   - `app/*window.cpp`：登录、管理员和学生窗口交互。
   - `app/graderepository.*`：CSV 读写、增删、排序和排名。
   - `app/studentdata.*`：学生成绩数据与计算。
   - `app/styles/app.qss`：Stitch 校园蓝界面样式。
   - `tests/test_core.cpp`：核心逻辑测试。

3. **每次只改一类问题**
   - 改界面时，主要修改 `.ui` 和 QSS。
   - 改数据规则时，先修改或新增测试，再改 C++ 代码。
   - 改完立即编译和运行，不要积累大量改动后一次性排错。

4. **按顺序验收**
   - 先运行核心测试。
   - 再检查管理员登录、导入、添加、删除、排序和导出。
   - 然后检查学生登录、成绩、平均分和排名。
   - 最后执行 `.\scripts\build-release.ps1` 生成发布包。

## 需要特别注意

- **不要随意修改 objectName**：C++ 通过 `lineEdit_account`、`tableWidget`、`pushButton_add` 等名称访问界面控件。
- **数据文件必须是 UTF-8、无表头、8 列**：学号、姓名、性别、英语、语文、数学、总分、排名。
- **不要相信文件中的总分和排名**：程序会根据三科成绩重新计算。
- **并列名次规则是 `1、2、2、4`**，修改排序逻辑时要保留该规则。
- **`grade.csv` 必须与 EXE 放在同一目录**，否则学生登录时无法找到成绩。
- **密码框必须保持 `Password` 模式**，这是作业明确要求。
- **表格必须整行选择且不可直接编辑**，删除功能依赖当前选中行。
- **不要只提交 EXE**：大作业应保留源码、`.ui`、`.pro`、QSS、数据文件和可运行发布目录。
- **打包后必须从 `dist` 目录实际启动一次**，防止遗漏 Qt 或 MinGW DLL。
